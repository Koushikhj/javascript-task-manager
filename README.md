# JavaScript Task Manager 🚀

An interactive Task Manager web application built using HTML, CSS, and JavaScript.

## ✨ Features
- Add new tasks
- Mark tasks as completed or undo completion
- Delete individual tasks
- Filter tasks by All, Pending, and Completed
- Display total, pending, and completed task counts
- Clear all tasks with confirmation
- Save tasks using localStorage, so they persist after refreshing the page

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- localStorage

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start managing your tasks!
